# دليل المشروع (شرح كل شيء)

## 1) كيف تشغّله
1. نزّل Godot 4.3 (نسخة Standard) من godotengine.org.
2. افتح المحرك → Import → اختر `project.godot` → ▶.
3. لو العربي يظهر بشكل غريب: الخط الافتراضي DejaVu يدعم العربية. للشكل الأجمل ضع `Cairo-Regular.ttf` في `assets/fonts/` وسيستخدمه اللعب تلقائيًا.

## 3) دورة اللعب
شقة → مكتب → عميل يتفاوض → إحاطة واختيار الحقيبة (4 أدوات) → مواقع وشهود (كل زيارة = ساعتان + بنزين) → لوحة التحقيق (استنتاج + حتى 3 أدلة) → تسليم للشرطة → نجوم ومكافأة وسمعة → يوم جديد وإيجار.

## 4) كيف تعمل الأنظمة
- **التفاوض:** كل رفض يرفع العرض بنسبة «الجشع» حتى «الميزانية القصوى». لو زاد عدد الرفض عن «الصبر» ينفجر العميل. العميل الذي يمثّل الغضب تبقى عيناه ثابتتين.
- **التوتر:** لكل شاهد توتر وثقة وتعب. السؤال العادي +3، المحيط +10، عن الحقيقة المخفية +25. ما تراه على الوجه = التوتر + **خط الأساس** (العصبي +25، البارد −25). الكاذب ينهار فقط لو التوتر ≥ حد الانهيار والثقة ≥ حد أدنى. لذلك **رتّب أسئلتك**: أسئلة سهلة لتعرف الأساس، ثم ضغط/دليل، ثم السؤال الحساس. كل سؤال يُطرح مرة واحدة.
- **المسح:** حرّك إصبعك ببطء داخل الدائرة. السرعة فوق 650 لا تكشف، وفوق 1500 تطمس. الأعصاب المنخفضة تهز الكاميرا. القفازات ترفع جودة الصور.
- **التقييم:** 10 نقاط لكل دليل حقيقي جيد (حتى 4) وخصم 10 للمضلل، 30 للمتهم الصحيح، 15 للأسلوب (ينقص 5 لكل فعل غير قانوني)، 15 للوقت والأعصاب. 85+ مكافأة كاملة، 60+ سبعون بالمئة، 40+ ثلاثون بالمئة، أقل من 40 لا شيء.
- **القرارات:** القانوني يرفع سمعتك عند الشرطة، والرمادي عند الشارع، وغير القانوني يعطيك سرعة أو دليلًا لكنه يخصم من الأسلوب والسمعة. «أصمت» خيار دائم وهو ما يحدث عند انتهاء الوقت.
- **الصعوبة (الإعدادات):** مبتدئ = لمعة حول عينيّ الشاهد عند التوتر العالي ووقت أطول، خبير = وقت أقل وانهيار أصعب.
- **الاقتصاد:** الإيجار 400 كل 7 أيام، البنزين 10 لكل موقع، كل قضية تأخذ يومًا. إن نزل مالك عن 100 تأتيك عروض أسهل. الإفلاس ينزلك لشقة أسوأ ولا ينهي اللعبة.

## 5) كيف تضيف قضية
1. انسخ `data/templates/case_template.json` إلى `data/cases/case_03.json` وعبّئه.
2. أضف/عدّل سطرها في `data/cases/index.json` واجعل `"playable": true`.
3. شغّل `python3 tools/validate_data.py` للتأكد من سلامتها.
القواعد: خيار صحيح واحد؛ كل دليل له `kind` (`real`/`misleading`) و`supports` (الإجابات التي يدعمها)؛ كل سؤال `hidden` كاذب يحتاج `truth` و`reveals`.

## 6) النشر والتصدير
- **ويب:** يتم تلقائيًا عند الدفع إلى `main` (فعّل GitHub Pages بمصدر Actions).
- **Android:** Actions → *Build Android APK* → Run workflow (لم يُجرَّب، قد يحتاج تعديلًا)، أو من المحرك: Project → Export → Android.
- **iOS:** يتطلب جهاز Mac وحساب مطوّر Apple.

## 7) رفع الملفات إلى GitHub
- من حاسوب: فك الضغط وارفع المحتويات (Add file → Upload files) أو `git add . && git commit && git push`.
- من الجوال بـ Termux: `unzip Violet-Files.zip` ثم انسخ المحتويات لمجلد المستودع واعمل `git add . && git commit -m "add game" && git push`.
- ملاحظة: ارفع محتويات المجلد (project.godot في الجذر) وليس المجلد نفسه.
